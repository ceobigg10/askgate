# MCP Guard 2.0: Universal Governance & Safety Engine

## Core Concept Inversion
* **Old Model:** Local Action Firewall for Terminal Developers.
* **New Model:** Universal Safety, DLP, and Policy Engine for Enterprise AI Agents.

---

## Technical Specifications & Feature Matrix

| Feature Module | Technical Mechanism | Primary Value |
| :--- | :--- | :--- |
| **DLP & PII Sanitization** | Intercepts tool inputs using regex + ML entity extraction; redacts API keys, credentials, and PII in-flight. | Prevents outbound sensitive data exposure. |
| **Budget & Rate Engine** | Implements token/invocation sliding windows per session, agent, or team. | Eliminates runaway agent costs and API overages. |
| **Contextual Policy Matrix** | Replaces static lists with dynamic policy logic evaluated against agent state and system context. | Enables situational guardrails without manual overrides. |
| **Multi-Channel Approvals** | Webhook triggers for Slack, Teams, and Push notifications with one-click decision payloads. | Removes CLI dependencies for human-in-the-loop steps. |
| **Audit & Replay Logs** | Encrypted JSONL stream of tool attempts, arguments, decisions, and system diffs. | Delivers SOC2 / HIPAA compliance readiness. |
